Every `conditions.*` builder and its options.

```js
import * as conditions from '@dnd-ed/jsshenanigans/conditions';
```

## IN_AIR

```js
conditions.IN_AIR({ ... });
```

| Option | Node key | Default | Description |
| --- | --- | --- | --- |
| `flip` | `FLIP` | `false` | If false, the player must be in the air. If true, the player must not be in the air. |

<Callout title="Default output">

```json
{
  "K_NAME": "AIR",
  "FLIP": false
}
```

</Callout>

## HAS_AWK_BAR

```js
conditions.HAS_AWK_BAR({ ... });
```

| Option | Node key | Default | Description |
| --- | --- | --- | --- |
| `amount` | `AMOUNT` | `5` | The amount of the awakening bar to check. Defaults to 5%. |
| `flip` | `FLIP` | `false` | If false, the player must have (amount) of awakening or more. If true, the player must have less than (amount) of awakening. |

<Callout title="Default output">

```json
{
  "K_NAME": "BAR",
  "AMOUNT": 5,
  "FLIP": false
}
```

</Callout>
