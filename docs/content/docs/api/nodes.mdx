Every `nodes.*` builder, its options, and the node key each option writes.

```js
import * as nodes from '@dnd-ed/jsshenanigans/nodes';
```

## WAIT

```js
nodes.WAIT({ ... });
```

| Option | Node key | Default | Description |
| --- | --- | --- | --- |
| `TIME` | — | `1` | How many seconds to delay the next NODE by. |

<Callout title="Default output">

```json
{
  "K_NAME": "WAIT",
  "TIME": 1
}
```

</Callout>

## SKILL

```js
nodes.SKILL({ ... });
```

| Option | Node key | Default | Description |
| --- | --- | --- | --- |
| `move` | `MOVE` | `"Divergent Fist"` | The skill to run. [no in-game documentation] |
| `speed` | `SPEED` | `1` | Multiplier of the Skill's speed. |
| `cancel_last` | `CANCEL LAST` | `false` | Cancels the previous NODE if set to true. |
| `enable_variants` | `ENABLE VARIANTS` | `true` | Enable variants instead of only using the base variant. [no in-game documentation] |
| `hold_for` | `HOLD FOR` | `0` | How many seconds to hold the skill for. Only applicable to holdable skills, such as Max Elephant. |
| `start` | `START` | `0` | Where to begin the Skill from, starting from 0 seconds. |

<Callout title="Default output">

```json
{
  "K_NAME": "SKILL",
  "MOVE": "Divergent Fist",
  "SPEED": 1,
  "START": 0,
  "HOLD FOR": 0,
  "ENABLE VARIANTS": true,
  "CANCEL LAST": false
}
```

</Callout>

## VELOCITY

```js
nodes.VELOCITY({ ... });
```

| Option | Node key | Default | Description |
| --- | --- | --- | --- |
| `force` | — | `null` | The direction where force should be applied towards. Higher values = bigger force (X, Y, Z) |
| `time` | `TIME` | `0` | How long the force should be active for. |
| `fade` | `FADE` | `false` | The force linearly fades to 0,0,0 over time, |
| `track` | `TRACK` | `false` | Force direction tracks the torso's orientation during the entire duration of the NODE. |

| `true_ragdoll` | `TRUE RAGDOLL` | `false` | Disables ragdoll cancel. |
| `relative_from_branch` | `RELATIVE FROM BRANCH` | `false` | Force direction is relative to the Branch origin. |

## HITBOX

```js
nodes.HITBOX({ ... });
```

| Option | Node key | Default | Description |
| --- | --- | --- | --- |
| `position` | — | `null` | The hitbox's position, the origin being the player's center. (X, Y, Z) |
| `rotation` | — | `null` | The hitbox's rotation, relative to the player's orientation. (X, Y, Z) |
| `size` | — | `null` | The size of the hitbox. (X, Y, Z) |
| `stun` | `STUN` | `1` | How long the stun on hit should last for, in seconds. |
| `stun_anim` | `STUN ANIM` | `false` | Plays a generic stun animation on the hit target. |
| `ignore_wakeup` | `IGNORE WAKEUP` | `false` | Ignore the wakeup stun immunity (disable for accurate M1s). |
| `damage` | `DAMAGE` | `1` | How much damage should be dealt on hit. |
| `debree` | `DEBREE` | `0` | If not 0, causes destruction. The value determines the Debree Fidelity, which is 2 by default. Negative values don't spawn debree. |
| `attack_type` | `ATTACK TYPE` | `"Melee"` | The hitbox's attack type. [no in-game documentation] |
| `blockable` | `BLOCKABLE` | `true` | The hitbox is blockable from the front. |
| `blockable_360` | `360 BLOCK` | `false` | The hitbox is blockable regardless of orientation. |
| `cancel_enemy` | `CANCEL ENEMY` | `true` | Cancels the hit target(s). |
| `clear_knockback` | `CLEAR KNOCKBACK` | `false` | Clears hit target(s) velocity, also cancelling their ragdoll. |
| `can_kill` | `CAN KILL` | `true` | The hitbox can kill the hit target(s). If disabled, the target(s) cannot receive more damage than their current health. |
| `hit_ragdoll` | `HIT RAGDOLL` | `false` | The hitbox can hit ragdolls. |
| `hit_user` | `HIT USER` | `false` | The hitbox can hit the user of the skill. |
| `single_target` | `SINGLE TARGET` | `true` | The hitbox can only kill one target. |
| `branch` | `BRANCH` | `"nil"` | Proceed to a BRANCH on hit. |
| `branch_target` | `BRANCH TARGET` | `"nil"` | Force the hit target(s) to proceed to a BRANCH. |
| `branch_finisher` | `BRANCH FINISHER` | `"nil"` | Proceed to a BRANCH if the hit was fatal. |
| `projectile_tag` | `PROJECTILE TAG` | `"nil"` | The name of a projectile's tag. If matched with an existing projectile, the hitbox's origin is set to the projectile's position. |
| `link_user` | `LINK USER` | `false` | Another player hitting this hitbox transfers the hit to the user instead. Typed loosely: the game accepted a number here, so it is not clearly a plain toggle. |
| `preview` | — | `null` | Editor-only timeline range, `[start, end]`. Not used at runtime. |

## VISUAL

```js
nodes.VISUAL({ ... });
```

| Option | Node key | Default | Description |

## TAG

```js
nodes.TAG({ ... });
```

| Option | Node key | Default | Description |
| --- | --- | --- | --- |
| `tag` | `TAG` | `"nil"` | The name of the tag. This name can be used as a variable by all TAG nodes. |
| `value` | `VALUE` | `"nil"` | Value of the tag. Can be a number, or a string of text. |
| `time` | `TIME` | `1` | How long the tag should be active for, if changed. |
| `check` | `CHECK` | `false` | Checks if the tag's value matches (value). Performing *less than* and *greater than* operations can be done by prefixing the value with &lt; or &gt; (e.g. &lt;1 for *less than 1*). |
| `add_remove` | `ADD/REMOVE` | `true` | Only applicable if Set[_value] is false. If true, adds +(value) to the tag's value. If false, subtracts. |
| `set_value` | `SET` | `true` | Replaces the tag's value with (value) |
| `branch` | `BRANCH` | `"nil"` | Only applicable if Check is true. The branch that shall be proceeded to if Check successfully completes the comparison operation (e.g. if the tag's value is equal to (value), then proceed to BRANCH.) |
| `last_hit` | `LAST HIT` | `-1` | Activates this NODE on a target hit in the last X seconds. |
