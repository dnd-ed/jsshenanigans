## How?

<details>
<summary>TL;DR, character codes are generated by compressing JSON through zstd and base64-encoding it.</summary>

The way character codes are generated is by taking the original JSON and
compressing it through [zstd](https://github.com/facebook/zstd) and then
base64-encoding it. This is very easy to reverse, and can be used to create
custom movesets externally without the need for Roblox or JJS.

Decoding a code with base64 and zstd gives the original JSON. From there, a
script can modify the JSON to create a custom moveset.
</details>

## Usage

First, install the library.

```sh
npm install jsshenanigans
```

Then import the library and create a character.

```js
import * as pts from "jsshenanigans";

const character = new pts.Character();
```

From here, you can create skills using `character.create.skill()`.

```js
character.create.skill("Super Cool Skill", { cooldown: 5 });
```

Check out `demo/demo.js` for a full example.

## Features

- [x] Support for every documented node, condition and property, including
  `PARTICLE`, `LOOK` and `SETMELEE`
- [x] Support for all skill types
- [x] Exports as a JJS-valid character code
  - I recommend you paste it into JJS to check if it's working, then copy the character block's export
- [x] Branch support
- [x] Variable names for animations, easing styles/directions, effects, etc
- [ ] Custom nodes
  - [ ] Domain node
- [ ] Fake rigs
  - [ ] Fake rig animations

## Requirements

Node.js **22.15+** (it ships `zstd` in `node:zlib`). No other runtime
dependencies.
